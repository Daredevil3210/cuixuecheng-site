# 个人主页

基于个人荣誉材料与 GitHub 仓库信息制作的静态个人网站，通过 GitHub Pages 公开托管。

- 网站地址：https://daredevil3210.github.io/cuixuecheng-site/
- 内容：个人简介、教育背景、荣誉奖项、证书展示、开源项目、联系方式
- 技术：纯 HTML / CSS / JavaScript，无需构建

## 本地预览

直接双击打开 `index.html`，或在本目录运行：

```bash
python -m http.server 8000
```

然后访问 http://localhost:8000

## 素材说明

`assets/img/` 下的证书图片均来自本人证书扫描件（《个人荣誉.pdf》与 PNG 原件），已统一压缩为 WebP 以提升加载速度。
